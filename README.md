# PIO Telegram UI

Telegram discussion-platform interface and UI integration prototype.

Solo-developed by [Vojislav Beric](https://github.com/Goodworkid0).

## What it does

- Landing page and discussion/dashboard interface.
- Telegram SDK integration and UI capability experiments.
- React components, Tailwind styling and integration notes.

## Stack

Next.js · React · TypeScript · Telegram Apps SDK · Tailwind CSS

## Getting started

Use Node.js and npm.

```sh
npm install
npm run dev
```

The source is under `src/`; `npm run build` creates the Next.js build. This is an interface prototype: landing-page examples and design documents may describe planned backend/API capabilities. A production backend is not included.

## Project status

Initial public source snapshot. Python syntax and source manifests were checked for publication; full application, infrastructure and external-service integration tests have not been run for this release. Local credentials, databases, sessions, uploaded content and machine-specific deployment files are excluded.
